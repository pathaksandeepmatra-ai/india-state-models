# India · 28 State Models

**One state. One capital flag.** Explore an interactive raised 3D model for every Indian state, with a waving flag at its capital and a snapshot of state politics.

## Open the model

👉 **[Explore all 28 state models](https://pathaksandeepmatra-ai.github.io/india-state-models/)**

Choose a state, then drag the model to rotate it. Scroll or use the zoom controls to get a closer look. Reset, Top, and 3D controls make it easy to change the view.

## What you’ll find

- A selectable 3D outline for each state
- The capital and the party flag shown at that capital
- The Chief Minister and party
- Assembly seats won by the governing party and its alliance in the latest election shown
- The Assembly’s total seat count
- A declared criminal-case count where available in the cited affidavit review

## A note on political data

Political details and election results are dated snapshots and can change. Declared cases are allegations recorded in candidate affidavits; a case is not proof of guilt. Check the linked source in the model for context and updates.

Take a look, pick a state, and share the model with anyone curious about India’s state politics.
